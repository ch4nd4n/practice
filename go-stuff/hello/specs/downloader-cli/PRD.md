# PRD - downloader-cli

## Problem
Need a reliable CLI to download files from HTTP/HTTPS URLs.

## Users
- Developers automating fetch operations.
- Operators running scripted downloads.

## Goals
- Download by URL to a local path.
- Show progress and clear errors.
- Support retries and timeout.

## Non-goals
- Full browser/crawler behavior.
- Torrent/P2P support.
