# PRD - pg-fund-cli

## Problem
Need a CLI to query Postgres for fund records and related metadata.

## Users
- Analysts/devs needing quick terminal-based lookup.

## Goals
- Query fund by name/symbol.
- Return concise table/JSON output.
- Safe defaults for connection handling.

## Non-goals
- Full DB administration.
- Write/update/delete operations in initial version.
